# Unkn0WnDPI 2.1.0

Один `.exe`: обход DPI на базе zapret + встроенный MTProto-прокси для Telegram,
трей и работа в фоне.

## Новое в 2.1.0

- **Обновление списков и IP из GitHub без перезапуска.** В «Настройках» появился
  пункт «Обновить списки и IP (GitHub)». Скачиваются `list-general.txt`,
  `list-google.txt`, `list-exclude.txt`, `ipset-exclude.txt` и `ipset-all.txt`.
- **Живое применение.** winws сам замечает изменение hostlist/ipset-файлов и
  перечитывает их на следующем соединении. Останавливать программу или обход
  не нужно.
- **Надёжность загрузки.** Сначала `raw.githubusercontent.com`, при недоступности —
  зеркала jsDelivr. Ответы проверяются, запись атомарная, прошлые версии
  сохраняются в `lists\backup\`. Пользовательские `*-user.txt` не меняются.
- **Режим без интерфейса:** `Unkn0WnDPI.exe --update-lists` — удобно для
  Планировщика Windows.
- **24 стратегии** с понятным порядком: `general`, `UNIVERSAL 1/2`, затем
  `ALT`, `ALT2`…`ALT13`, `EXP`, `FAKE TLS AUTO*`, `SIMPLE FAKE*`.
- Две универсальные стратегии: **UNIVERSAL 1** и **UNIVERSAL 2**.

## Установка

1. Скачайте `Unkn0WnDPI.exe` из assets ниже.
2. Запустите от имени администратора (нужен WinDivert).
3. Рабочие файлы создаются в `%LOCALAPPDATA%\Unkn0WnDPI`.

Windows 10/11 x64. Это не VPN: IP-адрес не меняется.
