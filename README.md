# Unkn0WnDPI — обход DPI в Windows

Консольная программа для обхода DPI с движком **zapret** (`winws.exe`) от
[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).
Один `.exe` — движок и 24 готовые стратегии встроены внутрь и распаковываются при первом запуске.
Также внутрь встроен локальный MTProto-прокси для Telegram (без внешних exe и отдельных процессов).

Все рабочие файлы хранятся в **`%LOCALAPPDATA%\Unkn0WnDPI`**, поэтому сам exe можно
запускать откуда угодно (рабочий стол, флешка, любая папка).

Windows 10/11 x64. Нужны права администратора (WinDivert).

---

## Запуск

1. Запустите **`Unkn0WnDPI.exe`** (программа сама попросит UAC).
2. Откроется консольное окно с интерфейсом.
3. Нажмите **Enter** на пункте «Запустить обход».
4. Если что-то не работает — выполните **«Авто-подбор стратегии»**: программа проверит
   все 24 стратегии и выберет лучшую для вашей сети.

Всё управление — **только стрелками**:

| Клавиша | Действие |
|---|---|
| `←` `→` | переключение раздела |
| `↑` `↓` | выбор пункта / прокрутка |
| `Enter` | выполнить |
| `Esc` | назад (в «Обзор»); в «Обзоре» — выход |
| `F4` | выход из любого раздела |

## Системный трей

Пока программа запущена, в трее висит иконка-замок:

- **зелёная точка** — обход работает;
- **красная точка** — обход выключен;
- **левый клик или двойной клик** — открыть консольное окно;
- **правый клик** — меню: «Открыть окно», «Запустить/Остановить обход», «Выход»;
- при первом запуске программа сама закрепляет иконку в видимой области трея
  (ключ сохраняется в `config\tray-key.txt`).

**Сворачивание/закрытие окна не завершает программу:** кнопка «×» (закрыть)
или «_» (свернуть) убирают консольное окно, а Unkn0WnDPI остаётся в трее и
продолжает работать в фоне — обход и встроенный MTProto-прокси при этом **не
останавливаются** (их держит отдельный фоновый процесс-«страж»). Двойной клик
по иконке или пункт «Открыть окно» в меню трея открывают окно заново, при этом
оно сразу выходит на передний план (не остаётся позади других окон).
Полностью программа завершается только через `Esc`/`F4` в окне или пункт
«Выход» в меню трея.

Если предыдущая копия по какой-то причине осталась висеть без окна, при
следующем запуске программа сама завершит её и продолжит работу.

Иконка также показывается в заголовке консольного окна и в самом файле `Unkn0WnDPI.exe`.

## Разделы

- **ОБЗОР** — запуск/остановка обхода, авто-подбор, проверка связи, журнал событий.
- **СТРАТЕГИЯ** — список всех стратегий; `Enter` применяет выбранную.
- **TG WS** — встроенный локальный MTProto-прокси для Telegram (см. ниже).
- **ЖУРНАЛ** — полный лог.
- **ДИАГНОСТИКА** — отчёт о системе: службы, VPN/прокси, DNS, hosts, доступность сервисов.
- **НАСТРОЙКИ** — игровой режим, автозапуск, служба Windows, обновление списков и IP из GitHub.

Статус в шапке: `RUNNING` — обход работает, `STOPPED` — выключен,
`OLD ZAPRET` — в системе уже запущен другой экземпляр zapret.

## TG WS — встроенный MTProto-прокси для Telegram

Раздел **TG WS** поднимает локальный прокси для Telegram прямо внутри
Unkn0WnDPI: **никаких внешних exe и отдельной папки**. Прокси работает в
фоновом процессе-страже, поэтому он не выключается, когда окно свернуто или
закрыто в трей. Это своя реализация протокола `dd` (MTProto-obfuscation v2) на
базе идей [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)
(MIT).

Как это работает:

1. Telegram подключается к `127.0.0.1:1443` по ссылке вида
   `tg://proxy?server=127.0.0.1&port=1443&secret=dd<32 hex>`.
2. Прокси расшифровывает 64-байтовый handshake секретом из настроек и
   устанавливает новое соединение с датацентром Telegram: WebSocket поверх TLS
   (`/apiws`), в том числе через домены Cloudflare-прокси upstream — они
   доступны там, где напрямую заблокированы IP датацентров. Если WS недоступен,
   используется обычный TCP:443.
3. Трафик ре-шифруется в обе стороны; IP адрес не подменяется, это не VPN.

Пункты раздела:

| Пункт | Действие |
|---|---|
| Запустить/Остановить MTProto-прокси | включает/выключает слушателя |
| Перезапустить прокси | новый сеанс с тем же секретом |
| Открыть в Telegram | открывает готовую `tg://`-ссылку |
| Скопировать ссылку | копирует её в буфер обмена |
| Новый secret | генерирует новый 32-символьный секрет (старую ссылку нужно заменить) |
| Запуск вместе с обходом | включение прокси при успешном запуске обхода |

Секрет и порт хранятся в `config\settings.json` (`TgSecret`, `TgPort`,
`TgAutoStart`). При первом запуске секрет генерируется автоматически.

## Обновление списков и IP

Пункт **«Обновить списки и IP (GitHub)»** в разделе «Настройки» скачивает
актуальные файлы из репозитория Flowseal и сразу применяет их:

| Файл | Источник |
|---|---|
| `list-general.txt` | `lists/list-general.txt` |
| `list-google.txt` | `lists/list-google.txt` |
| `list-exclude.txt` | `lists/list-exclude.txt` |
| `ipset-exclude.txt` | `lists/ipset-exclude.txt` |
| `ipset-all.txt` | `.service/ipset-service.txt` |

Сначала используется `raw.githubusercontent.com`, при недоступности —
зеркала jsDelivr. Скачанные файлы проверяются (HTML/мусор отбрасывается),
записываются атомарно, а предыдущие версии сохраняются в `lists\backup\`.
Пользовательские `*-user.txt` не изменяются.

**Перезапуск не нужен:** winws сам замечает изменение времени/размера
hostlist- и ipset-файлов и перечитывает их на следующем соединении. Программу
и обход останавливать не требуется.

То же самое можно сделать без интерфейса (например, из Планировщика Windows):

```powershell
Unkn0WnDPI.exe --update-lists
```

## Что обходит

| Что | Как |
|---|---|
| Discord (чат, CDN, голос) | TLS/QUIC-фрагментация + fake UDP |
| YouTube (сайт, картинки, видео) | обход QUIC/TLS, списки Google/YouTube |
| Заблокированные сайты | 33 тыс. строк IP + списки доменов |
| Steam, EA/FIFA, Call of Duty | игровой режим (TCP/UDP, порты) |
| Автозапуск | задача Планировщика Windows |
| Служба Windows | постоянный обход до входа в систему |
| Telegram | встроенный MTProto-прокси (WS через Cloudflare / TCP-fallback) |

**Это не VPN:** IP не меняется, серверные гео-блокировки не обходятся.

Используемые проекты с открытым кодом:
[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
и [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) — оба под лицензией MIT.

## Файлы

При первом запуске создаются:

```
%LOCALAPPDATA%\Unkn0WnDPI\
├── engine\        распакованный zapret (winws.exe, WinDivert)
│   └── lists\     списки доменов/IP, backup\ — прошлые версии
├── config\        settings.json, tray-key.txt
└── logs\          Unkn0WnDPI.log, diag-latest.txt
```

Ключи командной строки:

| Ключ | Назначение |
|---|---|
| `--selftest` | проверить движок, пресеты и сеть, затем выйти |
| `--update-lists` | обновить списки и IP из GitHub без запуска интерфейса |
| `--no-elevate` | запуск без запроса прав администратора |
| `--from-autostart` | режим автозапуска (включает обход через 3 секунды) |

Переменная `UNKN0WN_DPI_HOME` позволяет задать другой каталог данных (для тестов).

## Сборка

```powershell
cargo build --release
# результат: target\release\Unkn0WnDPI.exe
```

Требуется Rust (toolchain `x86_64-pc-windows-gnu` или `msvc`) и `windres` (MinGW) для иконки.
Движок и пресеты лежат в `assets/` и встраиваются в бинарник на этапе сборки.

Готовая сборка: **`D:\Unkn0WnDPI\Unkn0WnDPI.exe`**.
